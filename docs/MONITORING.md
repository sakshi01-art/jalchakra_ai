# Monitoring & Feedback Loop

Monitoring closes the planning loop after an intervention scenario is selected.

## Track

- Spring discharge observations
- Rainfall and seasonal signals
- Intervention status
- Water-availability changes
- Community or field-team observations

## Feedback

New observations should be compared with the planning assumptions. Differences can be surfaced for review and used to improve later scenario planning.

## Principle

**Plan → Act → Observe → Compare → Learn → Re-plan**

The monitoring module is a validation layer, not a guarantee that a simulated intervention outcome will occur in the field.
